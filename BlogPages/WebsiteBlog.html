Overview

This website was made using HTML and Bootstrap. It is a static website that is hosted on GitHub. With the help of Bootstrap it has allowed me to make a responsive website that looks good on all devices.

Initial Development

I first started my website in Wix and I ended up struggling to achieve the exact look I was going for, so I decided to start from scratch and make my own website using HTML and Bootstrap to allow maximum control, without it being too overwhelming for my limited HTML knowledge. Initially I aimed to start with my opening page and attempt to get the layout to look nice and then move to the other pages (hence why they are currently blank).
